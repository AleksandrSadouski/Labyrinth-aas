# Labyrinth-aas

Labyrinth-aas — это один из проектов из серии '-aas'. Является многопользовательской игрой, написанная в MVC на Laravel. Два игрока по очереди ищут выход из генерируемого лабиринта. Синхронизация происходит через polling. Это вторая версия проекта, написанная на Laravel. Проект в стадии разработки.
