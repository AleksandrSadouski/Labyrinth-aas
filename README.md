# Labyrinth-aas

Labyrinth-aas — это проект из серии работ '-aas', где два игрока соревнуются в прохождении процедурно-генерируемого лабиринта. Каждый игрок управляет своим персонажем, перемещаясь по клеткам лабиринта в поисках выхода. Побеждает тот, кто первым достигнет выхода. Игроки могут создавать комнаты, подключаться к ним, делать ходы, выходить из игры или отменять ожидающие комнаты. Вся статистика (победы, поражения, рейтинг) сохраняется в профиль игрока. Синхронизация происходит через polling. Это вторая версия проекта, написанная на Laravel.

## Структура проекта:

- **app/** — основная директория

    - **Models/** — модели Profile, Player, Room, Message
    - **Services/**
        - **AuthService** — аутентификация
        - **ProfileService** — управление профилем
        - **LeaderboardService** — таблица лидеров
        - **RoomService** — создание и подключение к комнатам
        - **MoveService** — логика хода
        - **CheckResultService** — проверка результата игры
        - **GameLeaveService** — выход из игры и отмена комнаты
        - **MessageService** — отправка сообщений
        - **PollingService** — пуллинг
        - **UpdateStatsService** — обновление статистики и рейтинга
        - **EloService** — расчет рейтинга Эло
        - **MazeService** — генерация лабиринта
        - **CodeGeneratorService** — генерация кода комнаты

## Геймплей

Это пошаговая многопользовательская игра на двоих. Игроки ходят строго по очереди: сначала первый игрок, затем второй, потом снова первый, и так до завершения партии. За один ход разрешается переместиться только на соседнюю клетку: вверх, вниз, влево или вправо. Проходить сквозь стены конечно же нельзя, поэтому каждый шаг требует внимательности и планирования. Цель игры: первым добраться до выхода из лабиринта.

Однако если первый игрок финиширует, а второй в этот момент всё ещё находится в игре, партия не заканчивается. Второй получает право походить ещё раз, что убирает нечестное преимущество первого игрока. Если после этого он тоже добирается до выхода, объявляется ничья. Если же второй игрок не успевает, то он проигрывает.

Помимо основной механики, в игре есть встроенный чат, который позволяет игрокам общаться во время матча, обсуждать ходы или просто поддерживать дружескую атмосферу. А благодаря процедурной генерации каждый лабиринт уникален: при создании комнаты можно настроить размер, ветвление и длину коридоров, что делает каждую партию непредсказуемой и требует от игроков гибкости и внимательности. Встроенная система Эло и лидерборд позволяет объективно оценивать уровень каждого игрока и стимулирует к развитию и конкуренции.

## История разработки

Это мой второй проект на Laravel, который изначально должен был стать первым, созданным к концу июня и являться рефакторингом процедурного [Labyrinth](https://github.com/AleksandrSadouski/Labyrinth). Но для изучения фреймворка я решил сделать проект с более простыми связями в БД и без синхронизации: [Dungeon-aas](https://github.com/AleksandrSadouski/Dungeon-aas). Но из-за того, что я недооценил сложность бизнес-логики, Dungeon-aas я делал дольше чем планировал, но он очень многому меня научил.

29 июля я приступил к полноценной работе над проектом Labyrinth-aas. Я не просто хотел перенести логику Labyrinth на архитектуру MVC, я хотел сделать полноценный апгрейд игры, сделав из прототипа полноценное API, что у меня в целом и получилось сделать. Отличия Labyrinth-aas от Labyrinth следующие:
1. Добавлена полноценная аутентификация и профиль игрока
2. Статистика игрока
3. Таблица лидеров
4. Ничья как один из возможных результатов
5. Чат во время игры
6. Рейтинг Эло
7. Возможность изменения имени
8. Настройка лабиринта

К 11 августа проект был завершён, но улучшения следуют и по сей день. Из сложностей в основном были путаница связей БД, продумывание ничьи и распределение на сервисы, что я сделал в последнюю очередь. А так, Dungeon-aas мне и сейчас кажется гораздо более сложным и продуманным проектом, несмотря на то, что там нет синхронизации и многопользовательских возможностей.

## API Эндпоинты

| Метод | Эндпоинт | Описание |
|---|---|---|

| POST | `/api/menu/join` | Подключение к существующей комнате |
| GET | `/api/menu/stats` | Показать статистику профиля |
| POST | `/api/game/moves` | Сделать ход в активной игре |
| POST | `/api/game/message` | Написать сообщение |
| POST | `/api/game/exit` | Выйти из комнаты |
| DELETE | `/api/game/cancel` | Отменить созданную комнату |
| GET | `/api/poll` | Пуллинг |

## Установка Labyrinth-aas

Клонировать репозиторий:

```bash
git clone https://github.com/AleksandrSadouski/Labyrinth-aas.git
cd Labyrinth-aas
```

Установить зависимости:

```bash
composer install
```

Настроить окружение:

```bash
cp .env.example .env
```

В файле .env указать настройки базы данных:

```bash
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=maze
DB_USERNAME=root
DB_PASSWORD=
```

Сгенерировать ключ и запустить миграции:

```bash
php artisan key:generate
php artisan migrate
```

Запустить сервер:

```bash
php artisan serve
```

Сервер будет доступен по адресу: http://127.0.0.1:8000
