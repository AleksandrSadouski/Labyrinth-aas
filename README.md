# Labyrinth-aas

Labyrinth-aas — это проект из серии работ '-aas', где два игрока соревнуются в прохождении процедурно-генерируемого лабиринта. Каждый игрок управляет своим персонажем, перемещаясь по клеткам лабиринта в поисках выхода. Побеждает тот, кто первым достигнет выхода. Игроки могут создавать комнаты, подключаться к ним, делать ходы, выходить из игры или отменять ожидающие комнаты. Вся статистика (победы, поражения, рейтинг) сохраняется в профиль игрока. Синхронизация происходит через polling. Это вторая версия проекта, написанная на Laravel. Проект в стадии разработки.

## Технологии

- **Backend:**
    - PHP 8.3
    - Laravel 13
    - MySQL
- **Архитектура Laravel:**
    - Eloquent ORM
    - API Resources
    - FormRequest
    - Middleware

---

## Структура проекта:

- **app/** — основная директория
    - **Http/**
        - **Controllers/** — контроллеры авторизации, меню и игровой логики
        - **Requests/** — реквесты для валидации входящих данных
        - **Resources/** — API ресурсы для форматирования ответов
    - **Models/** — модели
    - **Services/**
        - **MazeService.php** — генерация лабиринта с настраиваемыми параметрами (размер, ветвление, коридоры)
        - **CodeGeneratorService.php** — генерация уникальных кодов для комнат

## API Эндпоинты

| Метод | Эндпоинт | Описание |
|---|---|---|
| POST | `/api/auth/login` | Вход в профиль |
| POST | `/api/auth/register` | Регистрация профиля |
| DELETE | `/api/menu/logout` | Выход из профиля |
| POST | `/api/menu/editor` | Создание новой комнаты |
| POST | `/api/menu/join` | Подключение к существующей комнате |
| GET | `/api/menu/stats` | Показать статистику профиля |
| POST | `/api/game/moves` | Сделать ход в активной игре |
| POST | `/api/game/exit` | Выйти из комнаты |
| DELETE | `/api/game/cancel` | Отменить созданную комнату |
| GET | `/api/poll` | Пуллинг|

## Установка Labyrinth-aas

Клонировать репозиторий:

```bash
git clone https://github.com/yourusername/Maze-aas.git
cd Maze-aas
```

Установить зависимости:

```bash
composer install
```

Настроить окружение:

```bash
cp .env.example .env
```

В файле .env указать настройки базы данных:

```bash
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=maze
DB_USERNAME=root
DB_PASSWORD=
```

Сгенерировать ключ и запустить миграции:

```bash
php artisan key:generate
php artisan migrate
```

Запустить сервер:

```bash
php artisan serve
```

Сервер будет доступен по адресу: http://127.0.0.1:8000
